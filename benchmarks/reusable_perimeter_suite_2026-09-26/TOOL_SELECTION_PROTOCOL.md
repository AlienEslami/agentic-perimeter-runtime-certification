# Certified planning-tool portfolio

After generating the complete candidate studies, collect only plans whose independent checker passed the same initial-information, arrival, physical/service and absolute-expiry contract. Select the lowest nominal center-forecast weighted task cost among those plans. Candidate sources are the original MPC/repair study, the full-scenario MPC/repair study, and the separately verified reserve-refresh study.

The center-forecast objective is recalculated by the existing analytic-gradient predictor. Neither sampled medians nor realized outcomes are used to select a plan. The method therefore measures an implementable planning-tool selection rule. Each selected candidate retains its original certificate and command binding. The rule adds no theorem assumption and grants no authority to an unverified candidate.

Release this portfolio separately from each component study. Later methods can compare their proposed certified tools against the same candidate pool and contract family.
